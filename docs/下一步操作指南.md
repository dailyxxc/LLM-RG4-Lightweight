### 第三步：小规模测试运行（推荐）

在正式训练前，建议先进行小规模测试，验证环境配置正确。

#### 3.1 创建测试脚本

创建 `scripts/train_stage1_test.sh`：

```bash
#!/bin/bash
dataset="mimic_cxr"
base_dir="../LLM-RG4/mimic-cxr-jpg/2.0.0/files/"
sn_annotation="../LLM-RG4/final_single_view_no_long_add1score_sentence_level.json"
sw_annotation="../LLM-RG4/final_single_view_with_long_add1score_sentence_level.json"
mn_annotation="../LLM-RG4/final_multi_view_no_long_add1score_sentence_level.json"
mw_annotation="../LLM-RG4/final_multi_view_with_long_add1score_sentence_level.json"
vicuna_model="./hf/Tiny-Vicuna-1B"
rad_dino_path="./hf/rad-dino"
cxr_bert_path="./hf/BiomedVLP-CXR-BERT-specialized"
chexbert_path="./hf/chexbert.pth"
bert_path="./hf/bert-base-uncased"
version="train_stage1_2048_test"  # 测试版本
savepath="./save/$dataset/$version"

mkdir -p "$savepath"

python -u train.py \
    --dataset ${dataset} \
    --data_ratio 0.1 \  # 只使用10%的数据进行测试
    --sn_annotation ${sn_annotation} \
    --sw_annotation ${sw_annotation} \
    --mn_annotation ${mn_annotation} \
    --mw_annotation ${mw_annotation} \
    --base_dir ${base_dir} \
    --vicuna_model ${vicuna_model} \
    --rad_dino_path ${rad_dino_path} \
    --cxr_bert_path ${cxr_bert_path} \
    --chexbert_path ${chexbert_path} \
    --bert_path ${bert_path} \
    --batch_size 4 \  # 小batch size
    --val_batch_size 2 \
    --freeze_vm True \
    --savedmodel_path ${savepath} \
    --max_length 100 \
    --min_new_tokens 50 \
    --max_new_tokens 150 \
    --repetition_penalty 2.0 \
    --length_penalty 2.0 \
    --num_workers 4 \
    --devices 1 \
    --max_epochs 1 \  # 只训练1个epoch
    --limit_val_batches 0.1 \  # 只验证10%的数据
    --val_check_interval 0.5 \
    --num_sanity_val_steps 2 \
    --stage_class 1 \
    --llm_use_lora False \
    --llm_r 32 \
    --llm_alpha 64 \
    --lora_dropout 0.1 \
    --accumulate_grad_batches 2 \
    --loss_mode 'sentence' \
    --sentence_ratio 0.75 \
    --learning_rate 3e-4 \
    --visual_token_number 128 \
    --test_mode 'train_1' \
    --test_batch_size 4 \
    2>&1 | tee -a ${savepath}/log.txt
```

#### 3.2 运行测试

```bash
cd /mnt/nvme_disk/user8_data/BN5212-final-VLMR
bash scripts/train_stage1_test.sh
```

#### 3.3 检查测试结果

### 问题2：显存不足

**症状**: CUDA out of memory

**解决**:
- 减小 `batch_size`
- 增大 `accumulate_grad_batches`
- 使用更少的GPU
