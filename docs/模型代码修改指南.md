## 修改二：修改 Transformers 库中的 LLaMA 模型代码

### 为什么需要修改？

**关键原因**：项目使用了 **token-level 损失加权**，需要返回每个 token 的损失值（而不是平均损失），这样才能实现句子级别的加权。

**技术细节**：
- **默认行为**：`CrossEntropyLoss()` 默认 `reduction='mean'`，返回所有 token 的平均损失
- **修改后**：`reduction='none'` 返回每个 token 的损失值（形状为 `[batch_size, sequence_length]`）
- **用途**：项目代码中会对不同 token 的损失进行加权处理（例如句子级别的权重）

### 注意事项

⚠️ **重要提醒**：

1. **版本兼容性**：
   - 不同版本的 transformers 库，代码行号可能不同
   - 如果找不到第1192行，搜索 `CrossEntropyLoss` 关键字找到对应位置

2. **修改影响**：
   - 这个修改会影响所有使用 LLaMA 模型的项目（如果共享同一个 transformers 库）
   - 如果担心影响其他项目，建议使用独立的虚拟环境

3. **版本更新风险**：
   - 如果更新 transformers 库，修改会被覆盖
   - 更新后需要重新应用修改

## 自动化修改脚本

为了简化操作，可以创建一个自动化脚本：

```bash
#!/bin/bash
# modify_transformers.sh - 自动修改transformers库代码

# 找到transformers库位置
TRANSFORMERS_PATH=$(python3 -c "import transformers; import os; print(os.path.dirname(transformers.__file__))")

if [ -z "$TRANSFORMERS_PATH" ]; then
    echo "错误：找不到transformers库"
    exit 1
fi

LLAMA_FILE="${TRANSFORMERS_PATH}/models/llama/modeling_llama.py"

if [ ! -f "$LLAMA_FILE" ]; then
    echo "错误：找不到文件 $LLAMA_FILE"
    exit 1
fi

# 备份原文件
cp "$LLAMA_FILE" "${LLAMA_FILE}.backup"
echo "✓ 已备份原文件到 ${LLAMA_FILE}.backup"

# 查找需要修改的行
LINE_NUM=$(grep -n "loss_fct = CrossEntropyLoss()" "$LLAMA_FILE" | head -1 | cut -d: -f1)

if [ -z "$LINE_NUM" ]; then
    # 尝试其他可能的格式
    LINE_NUM=$(grep -n "loss_fct = nn.CrossEntropyLoss()" "$LLAMA_FILE" | head -1 | cut -d: -f1)
fi

if [ -z "$LINE_NUM" ]; then
    echo "错误：找不到需要修改的代码行"
    echo "请手动查找包含 CrossEntropyLoss 的行"
    exit 1
fi

echo "找到需要修改的行：第 $LINE_NUM 行"

# 执行替换
sed -i "${LINE_NUM}s/loss_fct = CrossEntropyLoss()/loss_fct = nn.CrossEntropyLoss(reduction='none')/" "$LLAMA_FILE"
sed -i "${LINE_NUM}s/loss_fct = nn.CrossEntropyLoss()/loss_fct = nn.CrossEntropyLoss(reduction='none')/" "$LLAMA_FILE"

echo "✓ 修改完成"
echo "请验证修改是否正确："
echo "  grep -n \"CrossEntropyLoss\" $LLAMA_FILE"
```

使用方法：
```bash
chmod +x modify_transformers.sh
./modify_transformers.sh
```

## 常见问题解答

### Q1: 如果找不到第1192行怎么办？

**A**: 不同版本的 transformers 库行号可能不同。使用以下命令搜索：

```bash
grep -n "loss_fct.*CrossEntropyLoss" transformers/models/llama/modeling_llama.py
```

找到所有相关行，然后查看上下文确定需要修改的位置。

### Q2: 修改后其他项目会受影响吗？

**A**: 如果其他项目也使用同一个 Python 环境，可能会受影响。建议：
- 使用独立的虚拟环境
- 或者确保其他项目也使用相同的损失计算方式

### Q3: 如何撤销修改？

**A**: 使用备份文件恢复：

```bash
# 恢复 CXR-BERT
cp ./hf/BiomedVLP-CXR-BERT-specialized/modeling_cxrbert.py.backup \
   ./hf/BiomedVLP-CXR-BERT-specialized/modeling_cxrbert.py

# 恢复 Transformers
cp transformers/models/llama/modeling_llama.py.backup \
   transformers/models/llama/modeling_llama.py
```

### Q4: 修改后需要重新安装库吗？

**A**: 不需要。直接修改源代码文件即可，Python 会使用修改后的代码。

## 总结

这两个修改都是**必需的**，不进行修改会导致：

1. **CXR-BERT修改缺失**：无法使用文本投影功能，模型加载可能失败
2. **Transformers修改缺失**：损失计算方式不正确，训练效果会受影响

**建议操作顺序**：
1. ✅ 先修改 CXR-BERT（项目内文件，风险较小）
2. ✅ 再修改 Transformers（系统库文件，需要小心）
3. ✅ 验证两个修改都成功
4. ✅ 进行小规模测试运行

完成这些修改后，就可以开始训练了！
