# 原作者权重文件说明

## 两个权重文件介绍

原作者仓库（https://github.com/zh-Wang-Med/LLM-RG4）提供了两个预训练模型权重：

### 1. LLM-RG4 (MIMIC-RG4) 权重
**下载链接**: https://drive.google.com/file/d/1eZMOEhgSmCt7VAVTjgTyVnMSUtW2Iktq/view?usp=sharing

**功能**: 
- 可以同时预测 **finding** 和 **impression** 两个部分
- 基于 **MIMIC-RG4** 数据集训练

**适用场景**: 
- 测试完整报告生成（包含finding和impression）
- 与原作者结果对比

---

### 2. LLM-RG4 (MIMIC-CXR) 权重
**下载链接**: https://drive.google.com/file/d/1aCE7PSLwugz3TrN0vlnGRH4aVboI_3Qo/view?usp=sharing

**功能**:
- 只能预测 **finding** 部分
- 基于 **MIMIC-CXR** 数据集训练

**适用场景**:
- 测试仅finding部分的生成
- 标准MIMIC-CXR评估

---

## 重要说明

### ⚠️ 架构不匹配

**这些权重都是基于 Vicuna-7B 训练的**，而您的项目使用的是：
- **Tiny-Vicuna-1B** (1B轻量级版本)
- **3层投影架构** (768→768→2048→embed_dim)

**因此这些权重不能直接用于您的项目！**

---

## 是否需要下载？

### ❌ 不需要下载的情况

如果您：
1. ✅ 正在使用 **1B 轻量级版本**（您当前的情况）
2. ✅ 需要**自己训练模型**
3. ✅ 不需要与原作者7B模型对比

**则不需要下载这些权重**，因为：
- 架构不兼容（7B vs 1B）
- 投影层结构不同（4层 vs 3层）
- 您需要重新训练适合1B架构的权重

### ✅ 需要下载的情况

如果您：
1. 想直接测试原作者7B模型的效果
2. 需要与原作者结果进行对比
3. 有足够的计算资源运行7B模型

则可以下载作为参考或对比基准。

---

## 师兄项目中的情况

根据 `BN5212-final-VLMR/README.md`，师兄项目提到了：

```
Download annotation files and pre-trained checkpoints from Hugging Face:
https://huggingface.co/datasets/enyulab/BN5212-VLMR-bigdata

Files included:
- dataset/annotation/: JSON annotation files
- save/mimic_cxr/: Pre-trained model checkpoints
```

**这些是师兄自己训练的checkpoints**，不是原作者提供的权重。

### 检查状态

当前项目中没有 `save/` 目录，说明：
- ❌ 还没有下载师兄的预训练权重
- ❌ 还没有开始训练自己的模型

## 建议

### 对于您当前的情况（1B轻量级复现）

1. **不需要下载**原作者的7B权重

   - 您使用的是1B架构，需要重新训练
   - 可以确保模型适配您的具体配置
   - 训练过程也是项目的重要组成部分

### 后续步骤

1. **准备模型文件** (`hf/` 目录)
2. **开始 Stage1 训练**

## 权重文件使用方式

如果将来需要使用预训练权重（如师兄项目的权重），需要：

1. **下载权重文件**到 `save/mimic_cxr/<version>/pths/` 目录
2. **在测试脚本中指定**：
   ```bash
   --delta_file ./save/mimic_cxr/<version>/pths/checkpoint_xxx.pth
   ```
3. **确保架构匹配**：权重必须与模型架构完全匹配
