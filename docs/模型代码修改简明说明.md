## 修改二：修改 Transformers 库的 LLaMA 模型代码

### 🎯 目的
修改损失函数的计算方式，从**平均损失**改为**每个token的损失**，以便实现句子级别的损失加权。

### 📝 技术解释

**修改前**：
```python
loss_fct = CrossEntropyLoss()  # 默认 reduction='mean'，返回平均损失
```

**修改后**：
```python
loss_fct = nn.CrossEntropyLoss(reduction='none')  # 返回每个token的损失
```

**为什么需要这样改**：
- 项目使用了**句子级别的损失加权**
- 需要对不同句子中的token赋予不同的权重
- 只有返回每个token的损失（而不是平均），才能进行这种加权

### ✅ 操作步骤

#### 步骤1：找到 transformers 库的位置

```bash
python3 -c "import transformers; import os; print(os.path.dirname(transformers.__file__))"
```

输出示例：`/usr/local/lib/python3.9/site-packages/transformers`

#### 步骤2：定位目标文件

```bash
# 将上面的路径替换为实际路径
TRANSFORMERS_PATH="/usr/local/lib/python3.9/site-packages/transformers"
LLAMA_FILE="${TRANSFORMERS_PATH}/models/llama/modeling_llama.py"

# 备份原文件（重要！）
cp "$LLAMA_FILE" "${LLAMA_FILE}.backup"
```

#### 步骤3：查找需要修改的行

```bash
# 查找包含 CrossEntropyLoss 的行
grep -n "CrossEntropyLoss" "$LLAMA_FILE"
```

通常在第1192行附近，但不同版本可能不同。

#### 步骤4：修改代码

找到类似这样的代码：
```python
loss_fct = CrossEntropyLoss()
```

或：
```python
loss_fct = nn.CrossEntropyLoss()
```

修改为：
```python
loss_fct = nn.CrossEntropyLoss(reduction='none')
```

#### 步骤5：验证修改

```bash
grep -n "reduction='none'" "$LLAMA_FILE"
```

应该能看到包含 `reduction='none'` 的行。

- 更新后需要重新应用修改
