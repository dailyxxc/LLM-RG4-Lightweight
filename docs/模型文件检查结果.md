## 💡 解决方案

### 方案A：使用现有的 TinyLlama-1.1B 模型（推荐）

如果您已经有 `TinyLlama-1.1B-Chat-v1.0` 模型，可以创建符号链接：

```bash
cd /mnt/nvme_disk/user8_data/BN5212-final-VLMR
mkdir -p ./hf

# 创建符号链接
ln -s /mnt/nvme_disk/user8_data/model_weights/TinyLlama-1.1B-Chat-v1.0 ./hf/Tiny-Vicuna-1B

# 验证链接
ls -la ./hf/Tiny-Vicuna-1B
```

**然后需要确认**：
- 模型是否兼容（TinyLlama 和 Tiny-Vicuna 的架构是否相同）
- 如果需要，更新训练脚本中的模型路径

### 方案B：下载真正的 Tiny-Vicuna-1B 模型

如果必须使用 `Tiny-Vicuna-1B`（与 TinyLlama 不同），需要从 Hugging Face 下载：

```bash
cd /mnt/nvme_disk/user8_data/BN5212-final-VLMR/hf

# 使用 huggingface-cli 下载

```

**注意**：需要确认 Hugging Face 上是否有 `Tiny-Vicuna-1B` 模型。

### 方案C：更新训练脚本使用 TinyLlama
